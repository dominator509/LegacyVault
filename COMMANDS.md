# Commands

Export `CI=true GIT_TERMINAL_PROMPT=0 GIT_PAGER=cat PAGER=cat DEBIAN_FRONTEND=noninteractive`. Legal commands are `sh scripts/install.sh`, `preflight.sh`, `lint.sh`, `format-check.sh`, `typecheck.sh`, `test-unit.sh`, `test-integration.sh`, `test-e2e.sh`, `build.sh`, `security-check.sh`, `dependency-audit.sh`, `smoke-test.sh`, `live-fire.sh`, `verify.sh`, and `production-readiness-check.sh`. Local start: `pnpm --filter @legacy/api start >.agent/state/api.log 2>&1 & echo $! >.agent/state/api.pid`; probe with curl and kill using the PID file. Adapter parity: `for f in AGENTS.md CLAUDE.md HERMES.md OPENCLAW.md; do awk '/PRIME-BLOCK-BEGIN/,/PRIME-BLOCK-END/' "$f" | cksum; done`.

Bootstrap diagnostics authorized by ADR-010: `git --version`, `node --version`, `corepack --version`, `pnpm --version`, `docker version`, `docker compose version`, and `df -h .`. When the installed Docker Desktop engine is stopped, start `C:\Program Files\Docker\Docker\Docker Desktop.exe` with PowerShell `Start-Process -WindowStyle Hidden`, then run `docker version` at most 30 times with two-second intervals. Windows bind failures may be diagnosed read-only with `netsh interface ipv4 show excludedportrange protocol=tcp`. Dependency metadata may be inspected without mutation using `pnpm view <package> version`. `sh scripts/install.sh` creates the first lockfile only when it is absent and requires `--frozen-lockfile` on every subsequent install. Local environment generation uses `sh scripts/generate-local-env.sh`; `sh scripts/generate-local-env.sh --rotate` is allowed only for development-secret rotation. Existing ignored local files with legacy crypto formats can be narrowly repaired without rotating service credentials using `sh scripts/repair-local-export-key.sh` and `sh scripts/repair-local-encryption-key.sh`. The real local dependency stack uses `docker compose up -d --wait`, `docker compose ps`, and `docker compose down`; destructive volume removal is not an ordinary command. Database migrations use `pnpm db:migrate` after readiness. Implementation formatting uses `pnpm exec prettier --write apps packages tests package.json pnpm-workspace.yaml tsconfig.json tsconfig.build.json compose.yaml scripts/security-check.mjs scripts/probes/redis_url.mjs`; the immutable blueprint/control prose and generated lockfile are excluded by `.prettierignore`. Coding agents must not invent commands. If a command is missing or stale, update this file first, citing repository evidence, with a Decision Log entry.

After an evidence-backed exact dependency or workspace manifest change, refresh the lockfile once with `pnpm install --no-frozen-lockfile`, then immediately prove determinism with `sh scripts/install.sh` and run `sh scripts/dependency-audit.sh`.

Better Auth schema SQL is compiled read-only from the installed, pinned provider API with `pnpm --filter @legacy/auth schema:compile`; review the output before transcribing it into a numbered migration. Do not run provider-generated migrations directly against production.
