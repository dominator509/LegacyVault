# External Evidence Boundary

This directory is intentionally empty of approvals. Production release requires
the signed, approved, or independently verified evidence listed by
`compliance/COUNSEL_AND_BUSINESS_REVIEW_CHECKLIST.md` and
`.agent/state/DEFERRED_EXTERNALS.md`.

Do not commit credentials, payment data, personal information, privileged legal
advice, restricted contracts, insurance policy details, or raw provider exports.
Where an artifact cannot safely be committed, store only an approved reference,
owner, review date, immutable hash, access location, and disposition.
